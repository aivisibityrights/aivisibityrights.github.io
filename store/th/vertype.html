ตัวอักษรสี่ตัวเป็นเพียงจุดเริ่มต้น VerType ช่วยให้คุณทบทวนตัวเองและบันทึกเรื่องคนรอบตัว ด้วยเครื่องมือส่วนตัวที่ใช้ออฟไลน์ได้

แผนที่ทีมงาน: คนรอบตัวคุณในที่ทำงาน

  • วางหัวหน้า เพื่อนร่วมระดับ และลูกทีมลงแผนที่ เพิ่มคนที่ยังไม่รู้ type ได้
  • เตรียมประชุม ให้หรือรับ feedback รับมือเส้นตายและความเห็นต่าง จากสิ่งที่เขาบอก สิ่งที่คุณสังเกต และข้อตกลงที่บันทึกไว้
  • เก็บสิ่งที่ลองและผลที่เกิดขึ้น ข้อแนะนำที่บันทึกว่าไม่เวิร์กจะไม่ถูกเสนอซ้ำในบริบทเดียวกัน
  • แยกเรื่องที่คุมได้ เรื่องที่ต่อรองได้ และเรื่องที่จะพักไว้ก่อน
  • เลือกผู้ฟังกับสถานการณ์ ดู PDF ส่วนตัวก่อนสร้าง แล้วตัดสินใจเองว่าจะส่งไปที่ไหน

ใช้บันทึกของคุณก่อน type มีไว้ตั้งคำถามและเสนอทางเลือก ไม่ได้ทำนายความสามารถ ผลงาน หรือพฤติกรรมของใคร

มากกว่าผลทดสอบ

  • สมุดคนรอบตัว: เก็บความสัมพันธ์และที่มาของ type สำรวจการเปรียบเทียบ แนวทางสื่อสาร และแผนที่กลุ่มดาวของคนที่คุณรู้จัก
  • การ์ดประจำวัน: ข้อคิด มุมมองใหม่ และสิ่งเล็กๆ ให้ลอง แชร์เป็นภาพและเก็บการ์ดที่เปิดแล้วในตู้สะสม
  • คู่มือของคุณ: ทำเครื่องหมายส่วนที่ตรง เพิ่มตัวอย่างของตัวเอง ซ่อนส่วนที่ไม่ใช่ และส่งออกคู่มือที่แก้แล้วเป็น PDF
  • Confidence Lab และกราฟผลตามเวลา: ทบทวนคำตอบและเปรียบเทียบผลของตัวเองแต่ละครั้ง
  • Type Wrap: ย้อนดูสิ่งที่เกิดขึ้นจากกิจกรรมที่บันทึกในเครื่องนี้
  • เรียนรู้ cognitive functions สำรวจเรื่องงานและการเรียน แบบฝึกพัฒนาตัวเอง และแนวทางใช้ AI

ทำแบบทดสอบสั้นหรือเต็ม หรือเลือก type ที่รู้อยู่แล้ว ผลแสดงความเข้มของคำตอบและบอกมิติที่ก้ำกึ่ง หน้าวิธีการแยกสิ่งที่วัดจากคำตอบ ค่าประมาณจากประชากร และคำอธิบายตาม type ออกจากกัน

การเช็คอินอารมณ์และการสะท้อนเรื่องความมั่นคงทางอารมณ์เป็นตัวเลือก แยกจาก type และไม่ใช่การวินิจฉัย

คุณเลือกเองว่าจะแชร์อะไร
